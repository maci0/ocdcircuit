# Research brief: fine-tuned AI models for PCB design

Pure research. No product decisions, no recommendations — claims only.

## Summary

- The strongest evaluated result for LLMs doing board-level schematic design is **HWE-Bench**: best model (Claude Sonnet 4.5) reaches **8.15% overall pass rate** across 300 tasks; static rule pass ~72% avg, dynamic sim pass ~59% avg. Models parse docs but "lack physical intuition" (Qu et al. — Tables III–V re-verified verbatim from ar5iv full text 2026-09-15: static avg 71.84% / dynamic avg 58.65% / overall 4–8%; authors attribute Industrial/Automotive highs to standardized-bus over-representation in pretraining).
- **PCB-Bench (ICLR 2026)** is the placement/routing reasoning benchmark: ~3,700 text instances + ~500 multimodal problems + 170 full projects; reports "substantial gaps" in spatial reasoning and constraint following (ICLR proceedings page).
- **CircuitLM (arXiv 2601.04505)** is a 5-stage multi-agent NL→CircuitJSON pipeline with a 50-component embedding KB and Dual-Metric Circuit Validation; evaluated on 100 prompts × 6 LLMs; spawned the AbijahKaj Qwen3-4B SKiDL fine-tune + 100k-example SFT dataset on HF Hub.
- On the Hub, the open fine-tunes that exist are small: **Qwen3-4B/3.5-4B LoRA for KiCad/SKiDL netlists** (AbijahKaj), **KiCad MCP Qwen3.5-4B GGUF** (empulse, 217 dl), **Gemma E2B KiCad chat** (CanadaDiver, CC-BY-NC-ND — non-commercial), Devstral/Ailiance LoRAs; plus **Microsoft SchGen (LoRA on GPT-oss-20b, NL→KiCad; full paper verified — 82% valid / 60.5% expert, beats GPT-5.2)** and **Masala-CHAI (+46% Pass@1; README + full paper agree)**; plus **YOLOv8/11/26 defect-detection/segmentation** models (keremberke, SanderGi, Janani-V, betty0) and **NVIDIA Cosmos 2B anomaly-generation** for inspection. No Gerber datasets found on HF (2 queries: `gerber`, `gerber file` — Hub-wide universals need broader search to assert firmly); no dedicated footprint/symbol generator models found on HF (1 query + KiCad-Q&A proxy check — same scope limit).
- IC-side fine-tunes (not PCB, but the closest mature SOTA): **NVIDIA ChipNeMo** (LLaMA2 7/13/70B + domain-adaptive pretraining; beats GPT-4 on 2/3 internal flows), **ChatEDA/AutoMage** (LLaMA2 SFT controller orchestrating RTL→GDSII tools; beats GPT-4 per abstract), **VeriGen** (CodeGen-16B SFT on Verilog; +41% syntactic correctness). Abstracts lead-verified round 6 (ChipNeMo v5, ChatEDA v4, VeriGen v1); PDFs not extracted. No PCB-footprint-recommendation or PCB-netlist-understanding fine-tune found as a primary contribution in the papers surveyed (7 verified + arXiv/HF searches above — not an exhaustive literature proof).
- Industry: **RL-from-physics confirmed only at Quilter and DeepPCB** (no named base models anywhere); **LLM orchestration confirmed at Flux Copilot** (LLM + 750K-part library + calculator + code interpreter, hallucinations admitted) **and JITX** (BYO-model + solvers + HFSS oracle). CELUS, Circuit Mind, Siemens/Cadence/Altium engines are undisclosed in reachable sources.

## Background

Board-level design is a zero-fault-tolerance physical discipline: pin multiplexing exclusivity, power integrity, thermal, SI/PI, manufacturability. Benchmarks have shifted from static text similarity to execution-driven verification (static rule checks + SPICE/LTspice transient sims), because n-gram overlap is meaningless for hardware (HWE-Bench §II-D). Two benchmark families now exist: schematic-generation (HWE-Bench, CircuitLM) and placement/routing reasoning (PCB-Bench, PCBRouteNet). Separately, manufacturing-side vision (defect detection/segmentation, anomaly synthesis) is the most mature open-model area.

## Key Findings (by theme)

### 1. Benchmarks: LLMs fail end-to-end board design today
- HWE-Bench: 300 tasks (GitHub + OSHWLab, 8 domains) + 2,914 structured IC datasheets; 4-stage pipeline (module partition → component assignment → local → global netlist); dual verification (static topology + LTspice transient). Results: static avg 71.84% (Claude Sonnet 4.5 best 77.73%, DeepSeek-v3 74.78%); dynamic avg 58.65% (Claude 67.92%); overall correctness 4–8% (Claude 8.15%, GPT-5.2 6.58%, DeepSeek-v3 5.12%, Gemini 3.1 Pro 5.16%, Qwen3-Max 5.03%, Grok-4 4.4%). Industrial/Automotive score highest (standardized buses over-represented in pretraining). Failure modes: pin-multiplexing conflicts, redundant-ground omissions, context overload at hundreds–thousands of pins, "functionally equivalent but physically illegal" nets. Mitigations proposed: signal-chain constraints, functional-group pin locking. (https://ar5iv.labs.arxiv.org/html/2603.18102)
- PCB-Bench (Li et al., ICLR 2026): ~3,700 expert-annotated text instances (1,800+ QA + choice versions: placement, routing strategy, DRC), ~500 multimodal image-text problems, 170+ complete projects (schematics + placement + docs). Finding: "substantial gaps… spatial placements, domain constraints, professional artifacts." Code/data: https://github.com/digailab/PCB-Bench (https://proceedings.iclr.cc/paper_files/paper/2026/hash/051f3997af1dd65da8e14397b6a72f8e-Abstract-Conference.html)
- tscircuit registry verified 2026-09-15 via official docs: `@tsci/<author>.<pkg>` on npm.tscircuit.com, cloud ESM/CJS bundling, Bearer-token endpoints (package_files/releases/builds + `/autorouting/jobs/create|get|get_output`). (https://docs.tscircuit.com/web-apis/the-registry-api)
- tscircuit `@tscircuit/prompt-benchmarks` exists as a system-prompt benchmark harness (npm; details not extracted — blocked on depth). (https://github.com/tscircuit/prompt-benchmarks/)

### 2. Schematic generation frameworks (multi-agent, grounded — not fine-tunes)
- CircuitLM (Hasan et al., IUT Dhaka, arXiv 2601.04505, Jan 2026, CC BY-NC-SA 4.0 — FULL HTML verified 2026-09-15): 5 stages — (i) LLM component ID, (ii) canonical pinout retrieval, (iii) expert-agent CoT, (iv) CircuitJSON synthesis, (v) force-directed SVG; 50-component embedding KB, dynamically extensible; Dual-Metric Circuit Validation vs human experts; 100 embedded prompts × 6 LLMs; high fidelity claimed on microcontroller-centric designs; code/data "upon acceptance." Results (100 prompts × 6 LLMs, DMCV = 0.6·S_logic + 0.4·S_comp, QA judge = Claude Sonnet 4.5): Gemini 2.5 Flash 8.503 > DeepSeek v3.1 8.377 ≈ Grok 8.373 > Qwen3-235B 8.347 > GPT-5 Mini 8.217 > Llama-3.3-70B 7.865. Key: S_comp ≈10 for all (retrieval grounds pins); S_logic 6.8–7.7 separates models; analog tasks (RC/LC) score ~0 across models ('analog reasoning gap'); no SPICE/ERC in pipeline (deliberate — MCU-centric, visual-first). Ablation surprise: REMOVING the CoT reasoning agent IMPROVES S_logic for most models (DeepSeek +0.75, Gemini +0.48) — reasoning traces hurt electrical accuracy except via GPT-5 Mini (−0.64 without it). KB: 50 components, ChromaDB + Qwen3-Embedding-0.6B. License CC BY-NC-SA (non-commercial, share-alike — not permissively reusable). Downstream: AbijahKaj/qwen3-4b-skidl model + kicad-netlist-sft-dataset cite it. (https://huggingface.co/papers/2601.04505 https://arxiv.org/abs/2601.04505)
- ICLabAgent (Wang et al., 2025, via OpenReview): multi-agent LMM for IC footprint geometry labeling from datasheets — cited by HWE-Bench for the datasheet→footprint parsing step. (OpenReview link per HWE-Bench ref [5]; page not fetched — partial.)
- ChatSCH (ACM): LLM-driven board-level schematic generation framework (title/venue only; body not fetched — blocked on depth). (https://dl.acm.org/doi/10.1007/978-981-92-3441-7_32)

### 3. Placement/routing learning (RL + GNN + datasets)
- Component-centric RL placement (Lim, arXiv 2602.23540, Feb 2026 — full HTML verified 2026-09-15 at https://arxiv.org/html/2602.23540v1): main component fixed at center, passives on discretized border slots; reward R_total = α·R_non-overlap + (1−α)·R_proximity; token state s=[p_state‖n_state] (passive+net one-hot); metric is TEWL (total Euclidean wirelength, not HPWL). Results on 9 in-house PCBs (8–24 passives): DQNnet (net-aware) best TEWL on 7/9; all MLs beat human TEWL on simple boards; overlaps 14/12/4/6 (SA/DQN/A2C/DQNnet), routing conflicts 22/13/16/16. Caveats now primary: U20 was human-designed double-sided but constrained to single-sided for the study; U115 A2C missing (−); no thermal/SI/crosstalk in reward (named as future work with Decision Transformers). Relevance lens: closest open analogue to our diffusion placer (wirelength + non-overlap objective, candidate framing) — placer-half only, no routing/rip-up stage.
- PCBRouteNet (Ren et al., IEEE TVLSI 2025): dynamic quadrilateral-flow dataset + benchmarks for ML routing. (https://ieeexplore.ieee.org/document/11142741 — abstract-gated; blocked on depth.)
- TRouter (Chen et al., IEEE TCAD 2023): thermal-driven routing via nonlocal crisscross attention. (Citation via HWE-Bench ref [17]; not fetched — blocked.)
- GNN circuit completion: node-pair prediction adding pull-ups/decoupling into schematics (Said et al.); Plettenberg et al. 2025 GNN auto-addition of optimizing components. (Citations via HWE-Bench refs [14][16]; not fetched — blocked.)
- Foundational chip-placement RL (Mirhoseini et al. 2020; Goldie & Mirhoseini 2020) listed as related work for the placement lineage (not fetched — background only).

### 3b. Adjacent IC-side fine-tunes (lead-verified 2026-09-15 via arXiv abs pages — not PCB, but closest mature SOTA)
- **ChatEDA** (Wu/He et al., CUHK, MLCAD 2023 → IEEE TCAD 2024, DOI 10.1109/TCAD.2024.3383347; arXiv:2308.10204 — FULL HTML v4 verified 2026-09-15): AutoMage controller = Llama2 + QLoRA instruction-tuning on generated EDA-tool scripts (4-bit, repo wuhy68/ChatEDAv1); pipeline = task decomposition → script generation → execution on OpenROAD/iEDA. AutoMage2 earns Grade A on 82% of ChatEDA-Bench cases vs GPT-4's 62% (GPT-4 can't separate B/C grades). Digital tool-scripting scope, not PCB. (https://arxiv.org/abs/2308.10204)
- **ChipNeMo** (NVIDIA, arXiv:2311.00176, v5 Apr 2024 — FULL HTML verified 2026-09-15): LLaMA2 7/13/70B + domain-adaptive tokenization + continued pretraining (DAPT <1.5% of from-scratch cost: 20.5k vs 1.72M A100-h at 70B) + SFT/alignment + domain-adapted retrieval. 70B-Steer beats LLaMA2-70B-Chat by +3.31 (model-only) / +1.81 (RAG) on 88-question chatbot bench; outperforms GPT-4 on chatbot + EDA scripts, competitive on bug summarization. RAG helps all models (+0.56 ChipNeMo / +1.68 GPT-4 / +2.05 LLaMA2). Proprietary evals. (https://arxiv.org/abs/2311.00176)
- **VeriGen** (Thakur et al., NYU, arXiv:2308.00708 — FULL HTML verified 2026-09-15): SFT of CodeGen-16B on GitHub Verilog + textbooks; +1.1% functional over GPT-3.5-turbo, +41% syntactic vs pretrained counterpart; training/eval scripts + checkpoints open-sourced. Note arXiv admin flag: text overlap with arXiv:2212.11140. (https://arxiv.org/abs/2308.00708)
- **ChipGPT** (arXiv:2305.14019): prompt-only frozen-LLM baseline — no-training reference. (https://arxiv.org/abs/2305.14019)
- **AutoChip** (arXiv:2311.04887): frozen LLMs + compile/simulate feedback loop, no weight training. (https://arxiv.org/abs/2311.04887)
- **PGR-DRC** (arXiv:2507.13355): unsupervised pre-routing DRC-violation prediction, 99.95% claimed on 28nm (single-node caveat). (https://arxiv.org/abs/2507.13355)
- **D2S-FLOW** (arXiv:2502.16540): LLM datasheet→SPICE extraction (EM 0.86/F1 0.92 claimed). (https://arxiv.org/abs/2502.16540)
- Framing survey: He et al., "LLMs for EDA: Future or Mirage?", ACM TODAES 2025 (DOI 10.1145/3736167) — taxonomy, not a model.

## Open Questions
1. Can small LoRAs (Qwen3-4B class) on 100k netlist examples beat grounded general LLMs on HWE-Bench/PCB-Bench? No head-to-head found.
2. Is there any open Gerber/copper-geometry training corpus? None found on HF; PCBRouteNet may be the closest (IEEE-gated).
3. What does Quilter train on ("millions of synthetic boards" per marketing)? No dataset disclosed; synthetic-generation method unpublished.
4. "GPT-6 Astra" in DeepPCB's comparison — real competitor or strawman label? Unverified.
5. Pin-multiplexing exclusivity and cross-module power coherence remain unsolved for LLMs — is the fix architectural (pin locking) or data (more multiplex examples)?
6. Footprint-geometry generation from datasheets (ICLabAgent direction) has no open model — reproducible SOTA unknown.
